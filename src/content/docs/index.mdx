Leoxy is a lightweight, on-demand proxy for small projects and development environments.

## Why Use Leoxy?

Leoxy is more than a reverse proxy. It's a lightweight traffic management layer designed to give your applications better control over incoming traffic without the complexity of a full-scale infrastructure platform.

#### Lightweight by Design

- Built with Go to keep resource usage low while handling application traffic efficiently.

#### Smarter Traffic Management

- Route requests to multiple upstream services with load balancing, health checks, and automatic failover.

#### Security at the Edge

- Protect your services with rate limiting, API key authentication, JWT, mTLS, and IP-based access control.

#### Multiple Protocols

- Handle HTTP, WebSocket, GraphQL, TCP, and UDP traffic through a unified proxy layer.

#### Built-in Observability

- Monitor proxy health and traffic through health endpoints, metrics, and optional profiling.

#### Simple Deployment

- Keep your infrastructure straightforward with a lightweight, configurable proxy that fits naturally into Docker-based environments.

**Leoxy — Control your traffic. Keep your infrastructure lightweight.**


## What you can configure

- HTTP routes with one upstream URL or a list of servers.
- TCP and UDP listeners with their own target addresses.
- HTTP security policies including rate limits, API key or JWT authentication, CIDR access rules, body limits, and TLS.
- Health and metrics endpoints for operating the service.

## Quick start

Pull the published [Leoxy image from Docker Hub](https://hub.docker.com/r/mohamed0699/leoxy) and run it:

```sh
docker pull mohamed0699/leoxy:latest
docker run --rm --cap-add=NET_BIND_SERVICE -p 80:80 -v "$PWD/leoxy:/app/leoxy" mohamed0699/leoxy:latest
```

Leoxy reads `/app/leoxy/leoxy_config.yaml` and creates a default config if that file is missing. The generated default does not contain your application routes; add your upstreams before sending application traffic. See [Installation](./installation/) and [Configuration](./configuration/). To build the CLI from source instead, follow the source build instructions on the installation page.
